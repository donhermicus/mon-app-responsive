# MonApp — Application Web Responsive

Application web moderne, responsive et performante créée avec HTML5, CSS moderne et JavaScript vanilla.

## ✨ Fonctionnalités

- Design **mobile-first** et entièrement responsive
- Navigation sticky avec menu hamburger sur mobile
- Section Hero avec call-to-action
- Grille de projets (cards)
- Section À propos avec statistiques
- Formulaire de contact fonctionnel (simulation)
- Animations et transitions fluides
- Accessibilité de base (ARIA, sémantique)

## 🛠️ Technologies

- HTML5 sémantique
- CSS3 (Flexbox, Grid, Custom Properties, clamp())
- JavaScript ES6+ (vanilla)
- Git & GitHub

## 🚀 Installation & utilisation

1. Clone le dépôt :
```bash
git clone https://github.com/TON-USERNAME/mon-app-responsive.git
cd mon-app-responsive
```

2. Ouvre `index.html` dans ton navigateur  
   ou utilise un serveur local :
```bash
# Avec Python
python -m http.server 8000

# Avec VS Code : extension Live Server
```

## 📦 Déploiement sur GitHub Pages

1. Va dans **Settings → Pages**
2. Source : Deploy from a branch
3. Branch : `main` / root
4. Enregistre

Ton site sera disponible à :  
`https://TON-USERNAME.github.io/mon-app-responsive/`
